The cluster

Worker processes by machine, the schedules (who ran the last fire), channels and feeds. Refreshes every 2 s. Kill a worker and watch its work move.

Retries and callbacks

charge: order ids ending in 7 fail once and are retried; every success runs the audit callback once (see the worker log).







  
Request / reply

  
price.call(sku) waits for the worker's value, or raises the task's own error. Try KB-01 and XX-99.

  
 

  






  
Spread over the workers

  
Sends tiny tasks and counts which machine and process ran each: the pool is shared, any web server may send.

  
 

  






  
Order per key

  
Three shipments each for ada and alan, sent at once. One customer's shipments run one at a time, in order; the two customers run side by side.

  

  






  
Cluster-wide limits

  
max_tasks=3 and rate="10/s" hold across all workers: it measures the peak at once and the rate.

  
 

  






  
Debounce

  
Ten quick edits of one product: only the last version is reindexed, the others are replaced.

  

  






  
Live events

  
An import task publishes progress and output. This page follows it with server-sent events.

  
 

  






  
Campaign (batch)

  
A batch of emails that starts paused. Resume it, cancel the rest, and one summary task runs at the end (worker log).

  

     
    
    
    
  

  






  
Users schedule posts

  
Runtime schedules: each owner may have 3 pending posts (the 4th is refused). They live in Redis, not in your database.

  

    
    
    
    
  

  

  






  
Live channel

  
sales:live: one handler for the whole cluster. staff:ada and staff:alan may read, only staff:ada may post, guest:eve is refused. Connect two tabs.

  

    
    
    
    
  

  






  
Watchlists (feeds)

  
Groups of symbols you subscribe to and drop at runtime. The cluster asks the vendor once per symbol however many tabs and servers watch it, stops when nobody does, and a new tab gets the last value at once. Try two tabs with the same user, one per web server, then Restore.
